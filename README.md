# Blue Protocol Star Resonance フロストメイジ火力計算ツール

フロストメイジ・**氷牙型**に特化した、スターレゾナンス向けの簡易火力計算ツールです。  
装備・幻想因子・イマジン・スキル/アビリティ・潜在心相晶を入力し、**3分間ローテーションの期待DPS**を計算します。

---

## 特徴

- **3分総ダメージ / DPS の期待値計算**  
  実際のローテーション（パーマフロスト→無尽極寒→ダウンタイム→準備期間）をフレーム単位でシミュレート
- **イマジン管理**  
  ボイス・ムークボス・ロローラ等のCDとチャージを動的に追跡し、使用バーストを自動判定
- **幸運の一撃・イマジンインパクト・星凍結**などの高確率/複合ダメージソースを期待値として計算
- **ステータス計算**  
  装備精練・刻印・改鋳・幻想因子・潜在心相晶の効果を反映
- **フロストメイジ固有アビリティに対応**  
  氷河の怒涛/霜襲来/星凍結/砕氷攻撃/氷慧/貫通氷槍 など

## ダウンロード・起動

1. [Releases](../../releases) から最新版の `BPSRfmCalculator.exe` をダウンロード
2. 任意のフォルダに置いてダブルクリックで起動
3. 初回起動時、`default_config.json`（デフォルト設定）と `ui_prefs.json`（UI設定）が exe と同じフォルダに生成されます

> **注意**: Windows Defender 等のウイルス対策ソフトが警告を出す場合があります。  
> PyInstaller でパッケージ化した個人製ツールのため、必要に応じて「許可」してください。

## 主要な計算項目

### ステータス計算タブ
- 魔法攻撃力 / 精練攻撃力 / 属性攻撃力
- 会心率 / 会心ダメージ / 幸運率 / 幸運の一撃倍率
- 万能 / 幻夢強度 / 各種ダメージ率

### ダメージ期待値タブ
| 項目 | 説明 |
|------|------|
| 3分総ダメージ | 初回極光から3分間の合計期待ダメージ |
| 3分DPS | 上記の秒間換算 |
| 3分内訳 | スキル別ダメージ割合 |
| 1バースト総ダメージ | パーマフロスト〜無尽極寒1回分の期待値 |
| バースト中玄氷維持 | 会心×幸運条件での玄氷維持可否 |
| 幸運の一撃期待数 | 3分間の発動回数 |
| イマジン使用 | バースト毎のイマジン使用状況（例: 4回目はスキップ） |

## 主要パラメータ

- **装備タブ**: 武器・防具・アクセの種類・精練Lv・サブステータス・刻印・改鋳
- **イマジンタブ**: イマジン選択・凸数（0〜5）
- **スキル/アビリティタブ**: タレントノード・各種アビリティのON/OFF
- **幻想因子タブ**: グレード・数量の入力（クラス固有含む）
- **潜在心相晶タブ**: 投影・絆ポイント・ノード選択
- **追加ステータスタブ**: 追加汎用/夢界/最終ダメ%・ローテーション設定

## 想定ローテーション

### 準備期間（極光発動前）
```
ウォータースフィア（キャンセル）
→ イマジン 2体
→ ブリザード（強化）
→ ウォータースフィア（キャンセル）
→ 極光・グレイシアルアンセム（キャンセル）
→ パーマフロスト（キャンセル）
```

### バースト期間
```
パーマフロスト（15秒）: フロストファング連打
→ 無尽極寒（10秒）: メテオストーム連打
```

### ダウンタイム
```
バースト開始時のメテオ2チャージ温存を最優先とし、
フロストファング / メテオストーム / レインフォール から期待値最大を選択
```

> **モーションキャンセルについて**  
> 本ツールは以下3スキルをキャンセル前提で計算しています。
> - **ウォータースフィア** — キャンセルにより後隙をカット
> - **極光・グレイシアルアンセム** — キャンセルにより後隙をカット
> - **パーマフロスト** — キャンセルにより後隙をカット
>
> これらをキャンセルせずに使用する場合、実際のDPSはツールの計算値より低くなります。

## 計算式（概要）

```
スキルダメージ（1ヒット）
  = (魔法攻撃力 × 防御係数 + 精練攻撃力 + 属性攻撃力) × スキル倍率 + Flat値
    × 汎用ダメージ × 属性ボーナス × 万能ボーナス
    × 物理/魔法増強 × 会心期待値 × 幻夢強度ボーナス
    × 夢界ダメージ × 最終ダメージ

防御係数 = 1 - 敵防御力 / (敵防御力 + 6500)
万能ボーナス = 1 + 万能% × 0.35
```

## 注意・免責

- 本ツールは有志による非公式ツールです。ゲーム公式とは無関係です。
- 計算値はあくまで**理論期待値**です。実測値とは5〜15%程度の差が生じることがあります  
  （完璧な実行を前提とするため、移動・遅延・運・サーバー遅延の振れ幅は含みません）
- 不具合・計算ミスを発見した場合は Discord **nullareph** までご連絡ください
- 丸めの処理でステータス計算では微小の誤差が発生しています。修正予定は今のところ無いです。
